# Большие Гонки

Самодостаточный модуль гонок кристаллических болидов для Foundry VTT. Основная проверенная среда — v13.351; манифест допускает v14, но живой прогон в v14 пока не проводился. Код не зависит от конкретной игровой системы, поэтому Forbidden Lands является тематической средой, а не технической зависимостью.

- Идентификатор: `fbl-need-for-speed`
- Версия: `0.16.10`
- Город проведения: Аллантре
- Интерфейс: русский. Полноценный `lang/*.json` i18n оставлен задачей перед возможной публикацией в каталоге Foundry.


## Изменения 0.16.10
- Исправлены все 16 функциональных и 24 малых замечания CodeRabbit: сетевые проверки, безопасное восстановление гонки, рендер без пит-лейна, переключение Worker на основной поток, звук, подсказки, доступность и переносимость тестов между ОС.
- Исправлено округление гоночного времени на границе минуты и отрицательных переходных значениях.
- Ускорены выбор и проверка пит-лейна: список окон вычисляется один раз, а проверка пересечений использует пространственный индекс трассы.
- Укреплена авторитетность сети: только ГМ может заявить восстановление хоста, а некорректные результаты не переводят гонку в завершённое состояние.
- Манифест получил рабочие URL обновления и архива релиза; синхронизация версии теперь проверяет все файлы до первой записи.
- Добавлены регрессионные проверки исправленных сценариев и расширен кроссплатформенный запуск тестов. Сетевой протокол остаётся версии 13.

## Изменения 0.16.6

- Исправлен критический сетевой фильтр ввода: фактическая команда управления содержит семь полей, а валидатор разрешал только шесть. Из-за этого хост отбрасывал газ, руление и остальные команды игроков, пока локальное предсказание создавало ложное ощущение частичного поворота.
- Полный пакет `throttle/steer/brake/reverse/boost/ram/drift` теперь принимается только от владельца назначенного болида; неизвестные поля по-прежнему отклоняются. Первый подтверждённый ввод немедленно снимает временный автопилот.
- Клиентский таймер изображения больше не привязывается заново к последнему полученному пакету. Он использует монотонную оценку часов симуляции, поэтому пакет с более высоким пингом не может отмотать всю сцену назад и вызвать последующее догоняющее ускорение.
- Сетевые снимки повышены с 10 до 15 Гц. Клиент держит буфер 140 мс и плавно догоняет более точную оценку часов без скачка. Локальное предсказание остаётся включённым для собственного болида.
- В диагностический отчёт добавлены смещение часов воспроизведения, последний образец задержки и текущее время показа. Протокол версии 13 сохранён.

## Изменения 0.15.0

- Сохраняется прежняя плавно меняющаяся ширина зон вылета, но на каждом круге появляются четыре длинных расширения. В центре каждого расширения локальная обочина достигает двойной обычной ширины и плавно возвращается к базовому профилю.
- Добавлены три физических покрытия зон вылета: трава, песок и гравий. Они генерируются длинными цельными секциями отдельно слева и справа, а не мелкой случайной мозаикой.
- Песок создаёт сильное сопротивление качению, резко ограничивает скорость, почти лишает болид разгона и гасит вращение. Выбираться из него эффективнее с выпрямленными колёсами.
- Гравий замедляет сильнее травы, уменьшает боковое сцепление и с ограниченной случайной частотой может ударить одно переднее колесо, резко подвернув болид. Между такими ударами действует таймер, поэтому эффект не превращается в постоянную дрожь.
- Трава стала относительно проходимой на малой скорости, но на высокой скорости быстро теряет боковое сцепление. Большой угол скольжения, резкое руление и частичный съезд одной стороной теперь легко разворачивают болид.
- Рендер обочин разделён по покрытию: трава получила растительные штрихи, песок волнистый рыхлый рисунок, гравий отдельную каменную фактуру. Все покрытия следуют фактической переменной ширине и тем же границам, которые использует физика.
- ИИ различает покрытия и выбирает более низкую скорость восстановления на песке и гравии.
- Добавлены регрессионные проверки двойных расширений, цельности песчаных и гравийных секций, сравнительного сопротивления покрытий, заноса на траве и случайного подворота на гравии.
- Сетевой протокол не менялся и остаётся версии 11. Геометрия и покрытия детерминированно воспроизводятся по зерну трассы на каждом клиенте.


## Изменения 0.14.0

- Асфальт пит-лейна теперь определяется по ближайшей из двух дорожных лент даже до формального переключения состояния маршрута. Линия въезда больше не может случайно считаться травой.
- Коллизии болидов переведены с круговых отталкиваний на ориентированные капсулы с массой, моментом инерции, импульсом в точке контакта, трением, вращением и зависимым от энергии удара повреждением.
- Столкновения с ограждением используют фактический корпус болида и видимый сегмент стены. Скользящие касания больше не гасят скорость как лобовой удар, а боковые удары разворачивают машину.
- На травяных зонах генерируются твёрдые объекты окружения: деревья, валуны, дома, амбары, мастерские, колонны, обелиски, статуи, башни, резервуары, трибуны и судейские вышки. Они не заходят на трассу или пит-лейн, имеют физические коллизии и рисуются поверх ограждений.

- Турнирные трассы собираются из нескольких независимых схем вместо одной деформируемой формы. Каждая получает одну или две длинные скоростные прямые и отдельный технический комплекс из шикан, шпилек и коротких участков для обгона.

## Изменения 0.13.0

- Пит-лейн полностью переведён на ручное прохождение. Болид больше не центрируется, не телепортируется и не запускается скриптом ни при въезде, ни после обслуживания.

- В настройках модуля доступны общий уровень, отдельные уровни болида, окружения, эффектов и интерфейса, а также выбор собственного аудиофайла для каждого звукового события.
- Исправлены пиктограммы заголовка ApplicationV2: кнопки закрытия снова отображаются классическим крестиком вместо точки.

- Сетевой протокол не менялся и остаётся версии 10.

## Управление

- `W` / `↑`: газ;
- `S` / `↓`: сначала торможение, после остановки задний ход;
- `A D` / `← →`: руление;
- `Space`: форсаж;
- `Ctrl` + руление: управляемый дрифт на достаточной скорости;
- `Shift`: таранный упор;
- `C`, `1`, `2`: переключение камеры;
- `M`: показать или скрыть мини-карту.

Canvas гонки должен находиться в фокусе. При потере фокуса, сворачивании вкладки или закрытии окна модуль немедленно сбрасывает ввод.
На всём пит-лейне болид остаётся под полным управлением игрока. Ограничитель плавно снижает превышение до 60 км/ч и не позволяет разогнаться выше этого значения. Для обслуживания водитель должен самостоятельно завести болид в голубую площадку и почти полностью остановиться. Только после этого машина фиксируется на месте для ввода слова. После завершения мини-игры фокус автоматически возвращается на Canvas, а болид остаётся ровно там, где водитель его остановил.

В сетевом и тренировочном заезде авторитетная физика выполняется в отдельном Web Worker. Поэтому свёрнутое или перекрытое окно ведущего больше не замедляет гонку для остальных клиентов до одного обновления в секунду. Статическое полотно трассы и мини-карты кэшируется. Гоночный Canvas использует адаптивную HiDPI-плотность с ограничением общего числа пикселей, а близкая камера использует ограниченный кэш тайлов высокого разрешения. Тайловые Canvas переиспользуются при движении камеры, чтобы не создавать новые GPU backing store на каждом участке трассы.

Спидометр показывает условную скорость в масштабе, уменьшенном втрое относительно внутренних физических единиц симуляции. В версии 0.10.0 физическая скорость болидов увеличена на 25%, а разница между специализированными и универсальными сборками стала заметно сильнее.


## Заряд, нагрев и пит-стопы

Форсаж расходует заряд непрерывно. При пустом заряде ускорение и визуальный эффект не включаются. Длительное удержание форсажа нагревает ядро: после 68% постепенно падают мощность, максимальная скорость и управляемость, а при 100% включается термическая блокировка. Форсаж остаётся недоступен до охлаждения ниже 48%.

В каждом заезде задаётся от нуля до четырёх обязательных пит-стопов. Пит-лейн постепенно отделяется от основной дороги длинной вилкой, расположен снаружи трассы и ограничен 60 км/ч. Ограничение не обрывает скорость мгновенно, а постепенно гасит превышение. Игрок сам рулит, тормозит и останавливает болид в голубой сервисной площадке. Проезд через неё на скорости ничего не запускает. После полной остановки игрок должен без ошибок набрать случайное русское или английское слово. Ошибка очищает ввод и заставляет начать слово заново. Успешное обслуживание полностью восстанавливает прочность и заряд, сбрасывает нагрев и засчитывает остановку. Без требуемого числа пит-стопов финиш не засчитывается.

## Звуковое окружение

Во время гонки модуль сводит несколько независимых слоёв: двигатель меняет громкость и высоту вместе со скоростью, ветер усиливается на разгоне, занос реагирует на боковое скольжение и траву, а окружение трассы плавно сменяется атмосферой пит-лейна. Отдельно воспроизводятся форсаж, столкновения, сигналы ограничения, начало обслуживания, обратный отсчёт, старт, новый круг и финиш.

Все параметры находятся в стандартных настройках модуля. Можно отключить звук целиком, раздельно отрегулировать громкость болида, окружения, эффектов и интерфейса, а также выбрать собственный аудиофайл для каждого слоя или события через файловый выбор Foundry. Зацикленные пользовательские файлы для двигателя, ветра, заноса и окружения должны иметь бесшовные начало и конец. Изменения применяются к открытому заезду без перезагрузки мира.

## Сетевая модель

Ведущий лобби является авторитетным симулятором. Игроки отправляют только ввод, а ведущий рассчитывает физику, столкновения, круги и результаты. Статическое состояние гонки передаётся один раз в `race-init`, а компактные динамические `race-frame` рассылаются с частотой 15 Гц. Клиент интерполирует кадры и применяет ограниченное визуальное предсказание локального болида, поэтому плавность не привязана напрямую к сетевой частоте.

Ввод отправляется немедленно при изменении состояния клавиш и затем раз в 100 мс как keepalive. Это остаётся безопасно ниже таймаута ввода 0,8 секунды и лучше переносит обычный сетевой джиттер.

Протокол версии 13 использует отдельный `raceId`, последовательности пакетов и номер тика симуляции, а также метаданные для локального предсказания разных сборок. Клиенты отбрасывают пакеты предыдущего заезда и устаревшие снимки. Ввод привязан к владельцу конкретного болида; при отсутствии пакетов он нейтрализуется через 0,8 секунды, а через 5 секунд временно включается автоматон. Возврат игрока и первый подтверждённый ввод немедленно возвращают управление. Только явный выход из гонки передаёт болид автоматону окончательно.

Текущий заезд, последний снимок и результаты хранятся у ведущего. Игрок может снова открыть окно и вернуться в гонку как участник или зритель. Если ведущий пропал до старта или после финиша, другой ГМ может принять управление лобби. Идущая гонка при таком восстановлении безопасно останавливается, потому что полное состояние авторитетной физики нельзя достоверно мигрировать между клиентами.

### Модель доверия

Foundry не передаёт модулю криптографически подтверждённую личность отправителя пользовательского socket-сообщения. Модуль проверяет роли, `raceId`, владельца болида и последовательности на уровне протокола, но всё равно рассчитан на доверенную домашнюю группу. Он не предназначен для публичных соревновательных серверов с враждебными клиентами.

### Ведущий в фоновой вкладке

Авторитетная симуляция использует накопление реального времени и ограниченный догон fixed timestep, поэтому не должна замедляться до частоты фонового `requestAnimationFrame`. Для наиболее стабильной сетевой игры ведущему всё равно рекомендуется держать вкладку Foundry открытой и не переводить устройство в сон.

## Надёжность и валидация

Любая сборка из настроек или сети проходит через whitelist-нормализацию. Неизвестные детали и таланты заменяются допустимыми, дубликаты талантов удаляются, а характеристики гонщика приводятся к законным 16 очкам.

Круг засчитывается только после последовательного прохождения 12 контрольных секторов. Положение в гонке основано на подтверждённых кругах и текущей проекции на трассу, а не на бесконечно накапливаемом ближайшем семпле.

Генератор проверяет самопересечения уже готового Catmull-Rom-полотна. При проблеме он детерминированно снижает нерегулярность трассы и в крайнем случае использует безопасный резервный профиль.

## Автоматические проверки

В архив входит независимый от Foundry набор тестов с тремя профилями:

```bash
npm test                 # быстрый release gate
npm run test:integration # Worker, renderer, несколько клиентов и ApplicationV2
npm run test:soak        # 200 fuzz-seeds геометрии и длительные гонки с ботами
npm run test:all         # все профили последовательно
```

`test:fast` проверяет нормализацию сборок, короткие физические инварианты, сетевые схемы, компактный `race-frame` и согласованность release metadata. `test:integration` покрывает lifecycle Web Worker, рендер, несколько виртуальных клиентов, снятие socket listener и запуск ApplicationV2. Длительные генеративные проверки и контактные гонки с 12 ботами вынесены в `test:soak`, чтобы обычный цикл разработки не зависел от сотен процедурных трасс.

Для локальной диагностики объём fuzz можно уменьшить или увеличить переменными `NFS_TRACK_FUZZ_SEEDS`, `NFS_WALL_FUZZ_SEEDS`, `NFS_PIT_FUZZ_SEEDS`, `NFS_RACE_SOAK_PROFILES` и `NFS_ELITE_BOT_SEEDS`.

## Сборка релизного архива

```bash
npm run sync-version
npm run test:all
npm run build
```

Готовый ZIP создаётся в `dist/`. Скрипт использует системную утилиту `zip` и исключает `node_modules`, `.git` и сам каталог `dist`.

## Установка

Распакуйте каталог `fbl-need-for-speed` в `Data/modules/`, перезапустите Foundry и включите модуль в мире.

Кнопка открытия находится в инструментах `Journal Notes`.

Старая версия с идентификатором `crystal-racing` считается Foundry отдельным модулем и должна быть отключена или удалена.


## Поверхности трассы

По обе стороны полотна находится трава переменной ширины. Левая и правая стороны генерируются независимо, а на внутренней стороне тесного поворота зона автоматически сужается, чтобы внешняя стена не складывалась в петли. На траве болид быстро теряет скорость, хуже разгоняется и слабее рулится. По внешней границе травы проходит видимая физическая стена. На финишной прямой и в закрытой части пит-лейна трава плавно сходит к нулю, поэтому стены подходят непосредственно к краю асфальта. Мягкая ходовая и специализация «Уличный гонщик» частично снижают штраф бездорожья.
