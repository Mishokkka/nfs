## Манифест и выпуск

Foundry сравнивает версию полученного manifest и скачивает его download URL:
[официальное описание установки и обновлений](https://foundryvtt.com/article/package-management/).
Поэтому замена только поля manifest не спасла бы старые установки, обращающиеся
к raw `main/module.json`.

Разрабатываемый manifest перенесён в `module-source.json`. Builder помещает
его **как fbl-need-for-speed/module.json в ZIP** и создаёт отдельный
`dist/module.json`. До первого релиза публичного корневого module.json нет;
в дальнейшем он хранит последнюю опубликованную версию, а не разработку.

После успешных CI/сборки workflow стабильного тега загружает ZIP, SHA256SUMS и
manifest в draft, публикует готовый release и затем обновляет legacy raw-main
manifest из опубликованного asset. Новый основной канал —
`releases/latest/download/module.json`. Скрипт проверяет публичность release,
tag/version/URL, готовность assets и размер manifest, отклоняет откат корневого
manifest; Content SHA защищает от конкурентной записи. CI проверяет существующий
публичный manifest по фактическому release asset. См. [RELEASING.md](RELEASING.md).

Флаги сверены с [gh release create](https://cli.github.com/manual/gh_release_create),
[gh release edit](https://cli.github.com/manual/gh_release_edit) и
[gh release download](https://cli.github.com/manual/gh_release_download).
Реальная публикация и запись в main не запускались.

## Проверки и ограничения

- Checkpoint: терминальный sequence, передача боту, оба режима resetInputs,
  следующие 300 шагов без расхождения; границы, дробь, NaN/Infinity/unsafe integer
  и отсутствие частичного изменения состояния при отказе.
- Город: принудительное исчерпание десяти обычных попыток, пять сложностей,
  два внешних seed; реальные проверки геометрии/стен/пита сохранены. Сравниваются
  полные samples/pit, район и декор могут отличаться.
- ГМ: предложение оставшегося игрока, takeover, старт без болида, checkpoint/F5,
  второе окно; ровно один Worker, своей машины у ГМа нет.
- Аренда: сохранения во время медленного ACK и после отказа; другой raceId
  не наследует готовность старого, ожидающий checkpoint пишется после ACK.
- Canvas: первый backing 300×150 при двух CSS/scale-сочетаниях, приоритетная
  подпись без исключения; неизменившийся resize не запекает карту/прибор снова.
- Metadata: draft/неполный release/отсутствующий ZIP/откат отклоняются. Sync/build
  во временном каталоге не меняют публичный manifest; запись module.json из
  настоящего ZIP распакована и сопоставлена с текущим исходником.

Регрессии sequence, резервного города, ГМа, аренды и Canvas падали до
соответствующих исправлений. Падение обычной городской генерации не заявляется.
Проверки планирования публикации не создают releases и не проверяют реальную
запись через GitHub API/политику ветки — это остаётся проверкой первого выпуска.

Локальный `npm run test:all` прошёл: 7/7 быстрых групп, 9/9 интеграционных групп,
все штатные репрезентативные soaks (120 track / 30 wall / 50 pit seeds,
городской заезд с обязательным питом, репрезентативный баланс гонок/ботов).
После дополнительной защиты от CRLF checkout отдельно повторён metadata suite.
Число групп не является числом отдельных assertions; seed-выборки не исчерпывающие.

Три прежние рекомендации о двух осях/yaw, силовом эллипсе/переносе нагрузки и
статических контактах prediction остаются согласованным следующим этапом.
Модель движения и протокол 19 не перерабатывались. Полный мир Foundry 13.351 +
Forbidden Lands 13.0.5 остаётся отдельной проверкой перед выпуском.
